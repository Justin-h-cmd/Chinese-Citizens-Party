# Chinese-Citizens-Party

# 中国公民党

**Chinese Citizens Party**

> 民主 · 人权 · 法治 · 公民参与

---

## 项目简介

本项目是“中国公民党”的官方网站概念设计。

网站采用简洁、庄重、公共机构门户风格的视觉设计，
用于展示党的政治理念、组织原则、党章以及政治目标。

本项目当前为静态网站，不依赖任何前端框架。

---

## 核心理念

中国公民党的政治纲领主要围绕以下原则：

- 人民主权
- 宪政与法治
- 基本人权
- 公民自由
- 民主选举
- 政党平等
- 司法独立
- 政府透明
- 权力制约
- 公民参与
- 和平政治竞争
- 反对个人崇拜
- 反对不受约束的绝对权力

---

## 政治目标

本党主张通过和平、非暴力和民主政治程序参与国家治理，
并以通过民主程序获得人民授权、成为执政力量作为长期政治目标。

最终政治理想是建立一个：

> 人民拥有真实政治参与权，
> 公民享有基本权利，
> 政府受到公众监督，
> 权力受到法律约束，
> 司法得到独立保障，
> 不同政治观点能够和平竞争。
